## 19. 2026-11-18 継続修正：試験枠 8799 の誤接続防止

### 19.1 原因と対策

ソースコード上、通常の Chrome 拡張機能が試験枠 8799 に全タブの `roster` を送信し、Bridge の `wantTab` が指定 ID の不一致時に URL 部分一致で別タブを選べる問題を確認した。これらは前節の既存タブ誤接続を説明し得る経路だが、実際の原因がこの経路だけだったとは断定しない。

- `background.js`：8799 を通常の探索対象から除外。`wantTab` は origin と pathname の完全一致で照合し、指定タブ ID が外れた場合の代替選択を禁止。ID がない場合は一意の候補だけを採用。
- `content.js`：`hello` に `pinnedPort` を追加。明示的な 8799 ピンを持たないタブの `dial(8799)` を拒否。
- `src/bridge-port-guard.js` と `src/bridge.js`：8799 では `roster` を受け付けず、明示的にピン留めしていない `hello` を拒否。通常 Bridge が試験枠からの譲渡要求を受けること、試験 Bridge が他の稼働 Bridge に譲渡を要求することも防ぐ。
- 隔離回帰テスト `test/bridge-port-isolation.test.js` と `test/bridge-background-isolation.test.js` を追加。実 TCP 8799 や既存ブラウザーは使用せず、Chrome API を模擬した。
