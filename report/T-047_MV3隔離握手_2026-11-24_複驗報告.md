## 四、網路隔離阻礙

拒絕轉送的 HTTP proxy 不等同完整網路隔離。三份 NetLog 均出現外部 IPv6 UDP 嘗試，失敗碼 -109。負向長時間案例另外出現 168.95.192.1:53、8.8.8.8:443、8.8.4.4:443，確認有 UDP DNS 送收及 TLS 資料收發。至少四個 DNS 傳送事件，各 28 bytes，共 112 bytes。

目前沒有真實 ChatGPT 對話內容遭外送的證據，但 fail-closed 網路要求確定未滿足。NetLog 僅為事後稽核，不能代替網路封鎖或證明所有流量都已捕獲。

已停止 Chromium 重跑。新增 T047_ISOLATED_NETWORK_CONFIRMED 啟動前必要條件；值為 0 的負向測試在 createRun 前退出 1，符合預期。環境變數本身不是隔離證明，未獨立驗證環境前不得設定為 1。
