### 新章節內容

放在「安裝」與「安全性」之間——這是使用面的資訊，不是設定參考。每份都含：

1. **席位埠位表**（4 席 × 主埠 / 子代理 / 瀏覽器）
2. **席位會被記住**，同一專案每次拿同一組埠
3. **席 0 就是原本的 8765**，單視窗行為完全不變，不用設定任何東西
4. **第二個視窗要用 `pairTab` 命令**，因為一般分頁只找 8765
5. **想自己指定埠就設 `port`**，設了就不自動取席

安裝段後另加一段引言式警告：兩邊擴充必須同版，更新後 `chrome://extensions` 重載擴充
**而且**重載 chatgpt.com 分頁，只做一件不夠。
